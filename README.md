# 빔프로젝터 투사거리·화면 크기 계산기

방 크기와 원하는 화면 크기로 필요한 투사비를 찾거나, 프로젝터의 투사비로 필요한 설치거리를 계산하는 한국어 정적 웹사이트 MVP입니다.

## 주요 기능

- 방 기준: 확보 거리와 화면 크기로 필요한 최대 투사비 계산
- 프로젝터 기준: 최소·최대 투사비로 필요한 설치거리 계산
- 16:9, 16:10, 4:3 화면 비율 지원
- 빈 값, 음수, 0, 범위 밖 숫자와 뒤바뀐 투사비 범위 검증
- 모바일 우선 반응형 UI, 키보드 탭 전환, 스크린리더용 결과 알림
- 투사비 설명, 계산 방법, 100인치 예시, FAQ 정적 콘텐츠
- 외부 라이브러리·폰트·추적 코드·네트워크 요청 없음

## 로컬 실행

빌드 과정은 필요하지 않습니다.

### VS Code Live Server로 실행

1. VS Code에서 이 폴더를 엽니다.
2. `index.html`을 엽니다.
3. 상태 표시줄의 **Go Live**를 누르거나 파일을 우클릭해 **Open with Live Server**를 선택합니다.
4. 브라우저에서 두 계산 모드와 모바일 화면을 확인합니다.

Live Server 확장이 없다면 `index.html`을 브라우저로 직접 열어도 계산기는 동작합니다. Python이 설치돼 있다면 터미널에서 아래처럼 정적 서버를 실행할 수도 있습니다.

```powershell
python -m http.server 8080
```

그다음 `http://localhost:8080`을 엽니다.

## 테스트

Node.js 기본 테스트 러너만 사용하며 패키지 설치는 필요하지 않습니다.

```powershell
node --test
```

테스트는 핵심 공식, 세 화면 비율, 두 모드, 고정 투사비, 입력 검증, 주요 HTML 구조와 외부 요청 부재를 확인합니다.

## 계산 기준

- 화면 대각선(m) = 인치 × 0.0254
- 화면 가로(m) = 대각선 × 가로 비율 ÷ √(가로 비율² + 세로 비율²)
- 화면 세로(m) = 대각선 × 세로 비율 ÷ √(가로 비율² + 세로 비율²)
- 투사거리(m) = 화면 가로 × 투사비
- 필요 최대 투사비 = 확보 거리 ÷ 화면 가로

계산에는 반올림하지 않은 값을 사용하고 화면 표시 단계에서만 반올림합니다.

## 추후 GA4 연결

현재는 측정 ID나 외부 추적 코드를 포함하지 않습니다. 유효한 계산이 완료될 때 `document`에서 `projector-calculator:calculated` 커스텀 이벤트가 발생합니다. 향후 이 이벤트를 구독해 GA4 이벤트로 전달할 수 있습니다.

이벤트 `detail`에는 계산 모드, 입력값, 내부 계산 결과가 들어갑니다. 개인정보는 수집하지 않습니다.

## 배포 후 SEO 설정

현재 실제 배포 주소가 없으므로 임의 URL을 넣지 않았습니다. 배포가 확정되면 다음을 설정해야 합니다.

1. `index.html`에 실제 주소를 사용하는 `<link rel="canonical">`과 `og:url` 추가
2. 공유 이미지를 만든 뒤 절대 URL의 `og:image` 추가
3. `sitemap.xml`에 실제 페이지 URL 추가
4. `robots.txt`에 절대 URL의 `Sitemap:` 지시문 추가
5. 필요하면 404 처리와 사이트맵 제공 경로가 호스팅 환경에서 정상인지 확인

## 범위와 주의사항

계산 결과는 후보 제품을 좁히는 참고값입니다. 제조사의 공식 설치 사양을 대체하지 않으며 렌즈 오프셋, 렌즈 시프트, 기기 크기, 장애물, 브래킷과 초단초점 모델의 특수 조건은 별도로 확인해야 합니다.

이 MVP에는 광고, 제휴 링크, 배포 설정, 원격 저장소 연결이 포함되지 않습니다.
